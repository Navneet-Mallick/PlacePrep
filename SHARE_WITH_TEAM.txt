================================================================================
PlacementPrep - Team Project Setup Guide
================================================================================

Hi Team! 👋

This is a group project for 4 people. Here's what you need to do:

================================================================================
STEP 1: GITHUB SETUP (Project Lead Only - Usually Navneet)
================================================================================

1. Open: GITHUB_SETUP.md
2. Follow instructions to:
   - Create PRIVATE repository on GitHub
   - Add 3 teammates as collaborators
   - Send GitHub link to teammates

================================================================================
STEP 2: EACH TEAMMATE (Everyone except project lead)
================================================================================

1. Accept GitHub invitation email
2. Clone the repository:
   git clone <github-link-from-team-lead>

3. Run TEAM_TESTING.md installation steps

4. Verify setup:
   python test_platform.py
   
   (Should show: ✓ ALL TESTS PASSED)

5. Let team know you're ready!

================================================================================
STEP 3: EVERYONE - RUN THE PROJECT
================================================================================

Start these in 3 separate terminals:

Terminal 1:
python manage.py runserver 8001

Terminal 2:
python ml/api/server.py

Terminal 3:
cd frontend
npm run dev

Then open: http://localhost:5173

Login with:
Email: admin@localhost.com
Password: admin123

================================================================================
COLLABORATION WORKFLOW
================================================================================

Everyone follows this:

1. Pull latest: git pull origin main

2. Create branch: git checkout -b feature/your-feature-name

3. Make changes and test: python test_platform.py

4. Commit: git commit -m "Add: your description"

5. Push: git push origin feature/your-feature-name

6. Create PR on GitHub

7. Teammates review and approve

8. Merge on GitHub

9. Everyone pulls latest: git pull origin main
